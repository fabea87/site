# Welcome — this blog is part of the site

Every post here is a plain `blog/*.md` file. When the site is rebuilt, these files are converted into static HTML pages — one per post, plus an index. The publish date comes from the file's **modification time**, so there is no metadata to maintain.

## What you can write

- **Headings**, *emphasis*, `inline code`, and [links](https://www.wmu.edu.cn)
- Lists:

1. Ordered items
2. Work exactly as expected

- Fenced code blocks:

```python
def hello():
    print("hello from a static blog")
```

- Blockquotes, images, and horizontal rules.

> A blog built into an academic homepage needs no runtime — just text, borders, and whitespace.
